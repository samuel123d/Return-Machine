# Return-Machine | Gestão de Logística Reversa

O Return-Machine é uma solução digital concebida para automatizar e organizar o processo de devolução de produtos. O sistema foca em simplificar a interface entre o utilizador e o centro de processamento, garantindo que cada item devolvido seja devidamente rastreado e categorizado.

**Link de Acesso:** [Visualizar Projeto](https://samuel123d.github.io/Return-Machine)

---

## Resumo do Projeto

A ferramenta permite a gestão eficiente de entradas de mercadoria para retorno, oferecendo um fluxo lógico que vai desde o registo da intenção de devolução até à confirmação de receção. É ideal para operações que necessitam de agilidade na triagem de itens e atualização de inventário.

## Estrutura de Diretórios

A organização do código privilegia a modularidade e a clareza para futuras expansões:

* **assets/**: Estilização personalizada, ícones de estado e recursos de UI.
* **src/**: Scripts de validação, cálculo de prazos e lógica de retorno.
* **index.html**: Painel principal de interação e registo.
* **status.html**: Módulo de consulta e rastreio de devoluções.

---

## Funcionalidades Principais

O projeto demonstra a capacidade de transformar regras de negócio complexas em software funcional:

> **Otimização de Processos**
> Implementação de um fluxo de trabalho intuitivo que reduz erros operacionais durante a entrada de dados, garantindo que o status de cada "máquina de retorno" esteja sempre visível para os administradores.
