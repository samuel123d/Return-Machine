# Return-Machine | Solução de Economia Circular

O Return-Machine é uma plataforma desenvolvida para incentivar a reciclagem através de um sistema de recompensas. A aplicação simula o funcionamento de uma "Reverse Vending Machine", onde o utilizador deposita materiais recicláveis (como garrafas PET e latas) e recebe créditos digitais em troca.

**Link de Acesso:** [Visualizar Projeto](https://samuel123d.github.io/Return-Machine)

---

## Resumo do Projeto

Este projeto foca-se na sustentabilidade urbana e no engajamento do consumidor. O fluxo consiste na identificação do material depositado, cálculo do valor correspondente e conversão em benefícios reais, como vouchers de desconto em supermercados e lojas parceiras.

## Estrutura de Diretórios

A organização do código foi pensada para simular a lógica de um terminal de autoatendimento:

* **assets/**: Estilização visual, ícones de materiais recicláveis e assets de UI.
* **src/**: Scripts de cálculo de créditos e gestão de saldo do utilizador.
* **index.html**: Interface do terminal de depósito.
* **rewards.html**: Painel de conversão de créditos em vouchers de desconto.

---

## Funcionalidades Principais

O projeto demonstra a aplicação de tecnologia para resolver desafios ambientais:

> **Sistema de Recompensas (Eco-Points)**
> Implementação de um motor de cálculo que converte diferentes tipos de resíduos em pontos acumuláveis, permitindo a integração com sistemas de fidelidade de parceiros comerciais.
